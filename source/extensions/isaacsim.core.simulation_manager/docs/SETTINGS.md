# Settings

## Settings Provided by the Extension

## exts."isaacsim.core.simulation_manager".default_engine
- **Default Value**: "physx"
- **Description**: Default physics engine to use (`physx` or `newton`).

### exts."isaacsim.core.simulation_manager".enable_default_callbacks
- **Default Value**: true
- **Description**: Enable the default timeline and stage lifecycle callbacks.
