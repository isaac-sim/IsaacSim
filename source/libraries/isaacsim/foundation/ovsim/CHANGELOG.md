## [7.0.0a1] - 2026-09-16

### Added

- Foundation interfaces for OV SIM.
- The alpha C++ API uses `timestamp` for data time codes and exposes `getAttributeName()`, `getValidAttributeNames()`,
  and `getComponent()` exception accessors.
- Installed C++ headers contain the public OV SIM interfaces; the registry is a private implementation detail.
